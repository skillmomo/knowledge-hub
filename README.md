### 看什么

  - 主打系列 [一书一skill](skills/one-book-one-skill/README.md)：一次读一本书，做成一个 AI skill，每个都配一支短片。
- [书单](reading-lists/README.md)：按主题整理的书单和读书笔记。

2. 把它的文件夹复制到你的 skills 目录（Claude Code 是 `~/.claude/skills/`）。
3. 正常跟 AI 说话就行，提到相关的事，AI 会自己用上。

## English

The GitHub home of 一书一skill (One Book, One Skill): one book at a time, turned into an AI skill. Reading lists and learning resources are shared here too.

### Explore

- [Skills](skills/README.md): Practical skills and workflows for AI.
  - Main series: [One Book, One Skill (一书一skill)](skills/one-book-one-skill/README.md) — one book at a time, turned into an AI skill, each with a short video.
- [Reading Lists](reading-lists/README.md): Themed reading lists and reading notes.
- [Learning Resources](resources/README.md): Tools, courses, and reference links.

### Quick start

1. Open [One Book, One Skill](skills/one-book-one-skill/README.md) and pick a skill.
2. Copy its folder into your skills directory (for Claude Code: `~/.claude/skills/`).
3. Talk to the AI as usual; when your request matches the topic, the AI will use it.

This collection is a work in progress. Only original content, lawful quotations, and links to publicly shareable resources are included.
