# 静屋 · Quiet Room —— 小屋改造 skill

屋子让人累，多半不是因为小，而是因为太亮、太满、太花、路被挡着、眼睛没地方歇。
AI 默认的习惯是「加东西」：推荐一堆收纳盒、一盏更亮的灯、几样网红装饰。这本书的做法相反：**先减、先排、再加**。

静屋让 AI 先回答五个问题，再给清单。

---

## 0. 来源与边界（先读）

- 来源：《室内设计基础》（中文 2014 年版，原著 2012 年；三位作者共同署名）；借景一条来自《居所的匠心：中国居住文化》。
- 引语纪律：下面都是据书整理的要点，**不是原话**。回答里不要加引号说成作者原话。
- 书里有日本的法规、建材模数和产品例子，有地区和年代边界；中国出租屋的情况是引申。
- 不说满：静屋让屋子更清楚、更好待；不保证「治愈焦虑」「提升效率」。暗处不能代替基本照度和安全。

---

## 1. 五件事

### 一、光：用光影，不用一样亮（《室内设计基础》印刷第 20–21 页）
- 照明不只是「够亮」。亮暗边界、阴影、几处光源的关系，才让屋子有深度。
- 暗处不一定是缺陷：它让屋子显得更深、更大，也把视线引到焦点上。
- 做法：分清**任务光**（书桌、床头看书）、**环境光**、**重点光**；回答三个问题——哪里要看清、哪里可以留暗、眼睛先落在哪里。
- 小屋常用改法：晚上关掉吸顶灯，开 2–3 盏低处的暖灯（台灯、床头灯、灯带）；光源放低、放到角落和墙上，不直射眼睛。
- 做错：一盏很亮的冷白吸顶灯照满全屋；暗角里放危险物品或台阶。

### 二、收纳：分类 → 选址 → 定尺寸 → 协调（印刷第 134–135 页）
- 不要先买一个大柜子再往里塞。从真实的东西出发：先分类，再按「在哪用」选位置，最后才定宽、高、层板、抽屉。
- 常用的放在顺手高度、靠近用它的地方；换季的、会变多的留余量或用可调层板；要展示的和要藏起来的分开。
- 收纳要和开门、走路、展示一起看，不能把路挤没了。
- 做法：先让用户（或从照片里）列出「地上、椅子上、桌上」的东西，分成 3–5 类，每类写清放哪。
- 做错：推荐一排同款收纳盒堆在墙边——东西只是换了个地方乱。

### 三、动线：屋子给的提示，要和人想走的一样（印刷第 16–17 页）
- 人会按经验和外观预测该怎么走、怎么开、怎么拿。门把手、通道方向、家具摆法都在给提示。
- 好动线不是逼人服从，是让屋子的提示和人的预期一致。
- 做法：画出每天最常走的 2–3 条路（门口→书桌、门口→床、床→衣柜），把挡在路上的箱子、凳子、椅子先挪开；椅子推进桌下；一块地毯可以「画」出路线。
- 注意：习惯有文化和地区差异，不要把一种习惯当成通用规律。

### 四、颜色和材料：一起定，不是最后随便配（印刷第 18–19 页）
- 颜色既影响情绪和行为，也是一套信息。形状、材料和颜色要一起考虑；先定形、再定材、最后随手配色，整体会散。
- 做法：先说清这间屋要什么感觉（例：安静、能专心）；定一个主色（常是木色或米白）、一个辅助色、最多一种点缀色；用真实样品在屋里的灯下看。
- 小屋常用改法：花床品、花窗帘、杂色收纳盒换成同一色系；露出木头、布、纸这些有纹理的材料。
- 边界：颜色心理有个人和文化差异，不要说「绿色=放松」这种一一对应。
- 做错：只用「高级灰」「奶油风」这类词，不给能买到、能复现的颜色。

### 五、借景：把外面的景借进视线，小中见大（《居所的匠心》园林篇）
- 中国私家园林在很小的地方，用分景、借景、曲折和远近层次，做出「小中见大」。核心不是堆东西，是安排看的顺序和尺度。
- 做法：找屋里**能看到的最好的东西**（一棵树、一片天、一面干净的墙），让坐着、躺着的视线落到它；厚花窗帘换纱帘；窗框当画框，窗前不堆东西；近处一盆植物、中间窗框、远处树，三层就有纵深。
- 边界：窗外没有可借的景，就借光（傍晚的天色、树影），或在墙上留一块空白当「远处」。

## 2. 回答怎么写（给 AI 的步骤）

1. **先看，不急着推荐买东西。** 有照片就读照片：列出灯、杂物、挡路的东西、颜色数量、窗外有什么。没照片就问 3 个问题：屋子多大、窗朝哪、最常在屋里做什么。
2. **按五件事各给一条改法**，每条一句话说「改什么」，一句话说「为什么」（对应上面的道理）。顺序固定：光 → 收纳 → 动线 → 颜色和材料 → 借景。
3. **先减后加。** 每条先写不用花钱的做法（关灯、挪开、收起、换位置），再写要买的，标出大概花费档位。
4. **给一张「改后会怎样」的描述**：人从门口进来，眼睛先看到什么、走到书桌要绕几步、晚上屋里几处光。
5. 用户要效果图或 3D：把五条改法写成同一机位的「改造前 / 改造后」两段提示词，机位、家具位置不变，只改光、收纳、颜色、窗帘。

## 3. 自检

- 有没有「全屋均匀亮」的建议？有就改。
- 推荐的东西，是不是比拿走的东西还多？是就删。
- 每天最常走的路是不是空出来了？
- 全屋颜色是不是能数得过来（主色＋辅助色＋最多一种点缀）？
- 坐在床上、书桌前，眼睛有没有一个可以歇的地方？
- 有没有把据书整理的话说成原话？有没有说满（「保证治愈」）？
