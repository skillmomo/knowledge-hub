# Between the Lines (字里行间)

A typography skill for AI. *One Book, One Skill (一书一 skill) · 05*

Author: skill整理员

## What it does

Type is not only read; it is seen. The space between letters and between lines decides whether a sentence sounds urgent or calm, loud or steady.

By default, AI tries to stress everything: bold, color, size, and icons all at once, default spacing everywhere, everything centered, every block filled. Every word shouts, so no sentence is heard. Between the Lines makes the AI set the relationship between type and space first, and the look of the letters second.

- **Scale**: size is relative; a small word beside a big one is what makes the big one big.
- **Letterspacing**: tight reads urgent, open reads calm; do not loosen body text; adjust large headlines pair by pair.
- **Leading**: measured baseline to baseline; give text room to breathe (Chinese body text usually needs more than Latin text).
- **Alignment**: edges carry tone; flush left is the safe default; narrow justified columns make white "rivers"; centering is for ceremony.
- **Hierarchy**: a few consistent cues; emphasis usually needs only one change.
- **Grid**: a flexible skeleton, not a cage; leave cells empty so the eye can rest.

It includes six knowledge chapters, a five-step working order (hierarchy, size, spacing, alignment and white space, grid) with an "emphasis count" check, and guidance for posters and covers, slides, web and app screens, long articles, menus, business cards and résumés, video captions, and logotypes.

## When to use it

When a poster, slide, page, or caption looks crowded or has no clear order. Typical requests mention "typography", "layout", "letterspacing", "line spacing", "alignment", "hierarchy", "grid", "too crowded", or "Between the Lines".

## How to use

Copy the `between-the-lines` folder into your skills directory (for Claude Code: `~/.claude/skills/`). The skill file (`SKILL.md`) is written in Chinese.

## Source

Based on reading notes from Ellen Lupton, *Thinking with Type* (first edition 2004, later revised). The skill is an original summary and contains no quotations from the book. The book is about Latin typography; the notes on Chinese text are extensions, not the author's words. The test numbers in the video (font sizes and boxed panels on a slide) are rough counts from generated CSS.
