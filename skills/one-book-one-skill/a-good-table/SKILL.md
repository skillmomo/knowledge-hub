# 一桌菜 · A Good Table —— 配菜 skill

每道都是大家爱吃的，放在一桌却没人吃——常见原因是：全是一个味（多半全是甜口），菜太多，热菜都在等人。
做法网上都有。这个 skill 不教怎么做菜，只管**怎么配、怎么上、怎么吃得好**。

---

## 0. 来源与边界（先读）

- 来源：袁枚《随园食单》（清乾隆年间），主要用「须知单」和「戒单」里讲配菜、上菜、请客的几条。原文可在维基文库《隨園食單/第一節》查到。
- 引语纪律：下面加「」的是原书短句；其余都是据书整理的要点和现代引申，**回答里不要把引申说成袁枚原话**。
- 袁枚讲的是清代文人家宴，口味和菜名都是他那个年代的。今天的菜名、份量、几人几菜，都是引申。
- 不讲做法：不写切法、火候、几分钟、放多少盐。用户问做法，一句话指给菜谱，回到「怎么配」。
- 不说满：不讲养生、食疗、减肥功效；有过敏、忌口、病人饮食，以用户和医生说的为准。

## 1. 五条配法

### 一、一道拿手菜当主角（戒目食、本分须知）
- 书里的道理：「目食者，贪多之谓也」——菜多不等于讲究；名手写字，写多了也有败笔。做菜的人该先做自己擅长的，不要为了讨好别人硬做不熟的。
- 做法：先问「你哪道菜做得最稳、最拿手？」它当主角，放桌子中间，份量最大。其余的菜都为它服务。
- 请客时最多试一道新菜，别让第一次做的菜担整桌的风险。
- 做错：请客就照网上「八道硬菜」清单全做一遍。

### 二、浓的旁边，配一口清的（配搭须知、独用须知）
- 书里的道理：一样东西做成菜，要有辅佐，讲「和合」；味道太浓重的，「只宜独用」，别再拿浓的去配它。
- 做法：主角很浓（红烧肉、炖牛腩、卤味），旁边放一道清口的（凉拌黄瓜、白灼青菜、拍萝卜）。吃两口浓的，夹一口清的，还想再吃。
- 注意：「浓菜旁边配清口」是据书引申，不是原话；书里原话是「清者配清，浓者配浓」，讲的是一道菜里主料和辅料要相配。两条不矛盾：一道菜里要合，一桌菜之间要有起伏。

### 三、一桌菜，每道一个味（变换须知、上菜须知）
- 书里的道理：「一物有一物之味，不可混而同之」；又说「天下原有五味，不可以咸之一味概之」。
- 做法：先给每道菜标一个主味：**甜、咸鲜、酸辣、清口、汤**。一桌里每个味最好都有，同一个味最多两道。
- 甜的有一道就够。爱吃的甜菜不是删掉，是留一道。
- 做法上常用的检查：把菜名排成一列，每道后面写一个字的味；一眼看去全是同一个字，就要换。
- 做错：红烧肉、糖醋排骨、可乐鸡翅、蜜汁叉烧、拔丝地瓜同一桌——每道都好吃，合起来腻。

### 四、菜数够吃就好（戒目食、迟速须知）
- 书里的道理：请客要早约，才有工夫「平章百味」；临时来客，就靠几样能很快上桌的家常菜。
- 做法：常用起点是「人数 + 1」道菜（含汤），按饭量增减；四个人四菜一汤通常够。宁可吃光再加，不要剩一大半。
- 一个人吃：一个主角 + 一口青菜（或一碗汤），就是完整的一顿。
- 做错：用盘子数撑面子，最后一半没动。

### 五、上菜有先后，人等菜，别让菜等人（上菜须知、戒停顿）
- 书里的道理：「咸者宜先，淡者宜后；浓者宜先，薄者宜后；无汤者宜先，有汤者宜后」；「虑客酒多，则胃疲矣，须用酸甘以提醒之」。又批评「性急主人，每摆菜必一齐搬出」——菜一停顿，鲜味就没了。
- 家里常用的顺序（引申）：凉菜先摆好 → 主角（浓的、肉）先上 → 怕放的（鱼、炒青菜）等大家坐下再出锅 → 汤最后。吃到一半腻了，上一道酸的或清口的。
- 做法：把菜分三类——**能提前做好的**（凉菜、炖菜、汤）、**能等一会儿的**、**必须现做现吃的**（炒青菜、蒸鱼）。按这个顺序做，现做的留到人齐。
- 主人也要坐下吃。安排时给自己留出坐下的时间。
- 做错：提前两小时全部做好，等人到齐一起端，热菜都凉了。

## 2. 不同的饭，同一个道理

| 场合 | 主角 | 配法要点 |
|---|---|---|
| 请朋友来家 | 你最拿手的一道 | 五个味各一道，人数 + 1；凉菜先摆，怕放的等人齐再做；主人能坐下 |
| 一个人的晚饭 | 一道简单的主菜 | 一个主角 + 一口青菜或汤；不必凑盘数 |
| 给爸妈做一顿 | 他们最爱吃的那道（常是家里的老菜） | 不为名贵食材买单——书里说「豆腐得味，远胜燕窝」；口味偏淡、偏软时跟着他们 |
| 年夜饭、生日饭 | 家里的「招牌菜」 | 菜多时按「味」分组，每组一个主角；分批上，不一次摆满 |

## 3. 回答怎么写（给 AI 的步骤）

1. **先问三件事**（用户没说时）：几个人、谁来吃（朋友 / 自己 / 爸妈 / 孩子）、你哪道菜最拿手。有忌口、过敏也顺便问。
2. **定主角**：一道，说明为什么选它。
3. **配一桌**：列出菜单，每道后面标一个味（甜 / 咸鲜 / 酸辣 / 清口 / 汤）和它的作用（主角 / 解腻 / 补一个味 / 收尾）。
4. **砍和留**：用户原来想做的菜，哪道留、哪道下次再做，说清理由（例如「甜的已经有一道」）。
5. **排上菜顺序**：按「先摆 → 先上 → 人齐再做 → 最后」写成一条时间线，标出哪道必须现做。
6. **一句话收尾**：说清这桌菜「吃起来会怎样」，不说「保证好评」。

用户给了上次的菜单、问「为什么没人吃」时：先把每道标上味 → 指出最主要的一个问题（全是一个味 / 菜太多 / 热菜等太久）→ 只改这一条，给出新菜单。

---

## 4. 自检清单

- [ ] 有且只有一道主角，是用户拿手的
- [ ] 每道菜标了一个味，同一个味不超过两道，甜的最多一道
- [ ] 浓的菜旁边有一道清口的
- [ ] 菜数大约是人数 + 1，没有为了面子加盘
- [ ] 有上菜顺序，怕放的菜等人齐再做，汤在最后
- [ ] 没有教做法（切、炒、火候、几分钟）
- [ ] 加「」的只有原书短句，引申没有说成袁枚原话
- [ ] 没有养生、食疗、功效的说法

## 5. 例子

**用户**：朋友们又要来家里聚会啦，做什么菜好呢？上次做的都是大家爱吃的，可是大家都没吃多少。上次是：红烧肉、糖醋排骨、可乐鸡翅、蜜汁叉烧、拔丝地瓜、糖醋里脊、红烧茄子、红豆汤。

**好的回答（要点）**：
- 原因：八道菜有七道是甜口，汤也是甜的；八个菜四个人，太多。
- 主角：红烧肉（你最拿手）。
- 新菜单（四人五道）：红烧肉（甜·主角）、凉拌黄瓜（清口·解腻）、清蒸鱼（咸鲜）、酸辣土豆丝（酸辣）、番茄蛋汤（汤·收尾）。
- 糖醋排骨下次当主角；这次甜的有红烧肉一道就够。
- 顺序：黄瓜先摆 → 红烧肉先上 → 大家坐下再蒸鱼、炒土豆丝 → 汤最后。人等菜，别让菜等人。
