## 中文

一次读一本书，把书里的核心方法做成 AI 能照着用的 skill。

每个 skill 把一本书变成 AI 思考、做事、做图、布置空间、写东西时可以照做的步骤，并配一支短片。skill 文件（`SKILL.md`）用中文写；每个 README 都有中文和英文。

作者：skill整理员

### 怎么用

把某个 skill 文件夹（例如 `quiet-room`）复制到你的 skills 目录（Claude Code 是 `~/.claude/skills/`）。之后正常跟 AI 说话，提到相关的事（比如「我的小屋怎么布置」），AI 就会用上它。

### 说明

skill 都是据读书笔记的原创整理，除少量注明出处的短引文外，不含书的原文。书外的用法（例如把构图用在 PPT 上）是引申，不是作者原话。

## English

One book at a time, distilled into a working method for AI.

Each skill turns the core ideas of one book into steps an AI can follow when it thinks, works, or makes images, spaces, and writing. Each skill has a short video. Skill files (`SKILL.md`) are written in Chinese. Every README is in Chinese and English.

Author: skill整理员

| # | Skill | Book | For |
| --- | --- | --- | --- |
| 01 | [Half Moon (半月)](half-moon/README.md) | Onishi Yoshinori's aesthetics trilogy (《日本美学三部曲》) | Japanese-style aesthetics for images, spaces, and writing |
| 02 | [Hollow (空处)](hollow/README.md) | Chen Guying, annotated *Laozi* (《老子注译及评介》) | Thinking, working, and making with Laozi's "useful emptiness" |
| 03 | [Where the Eye Lands (落点)](where-the-eye-lands/README.md) | Ian Roberts, *Mastering Composition* (《构图的艺术》) | Composition for images, slides, covers, photos, and spaces: one focal point |
| 05 | [Between the Lines (字里行间)](between-the-lines/README.md) | Ellen Lupton, *Thinking with Type* | Typography for posters, slides, pages, and captions: type and the space around it |
| 06 | [Quiet Room (静屋)](quiet-room/README.md) | 《室内设计基础》 (*Basics of Interior Design*) and 《居所的匠心》 (on Chinese dwellings) | Small-room makeovers: light, storage, path, color, borrowed view |
| 14 | [A Good Table (一桌菜)](a-good-table/README.md) | Yuan Mei, 《随园食单》 (*Recipes from the Garden of Contentment*) | Menu planning: for guests, for one, for parents — what goes together and in what order |

### How to use

Copy a skill folder (for example `quiet-room`) into your skills directory (for Claude Code: `~/.claude/skills/`). Then talk to the AI as usual; when your request is about that topic (for example "how should I arrange my small room?"), the AI will use the skill.

### Notes

Skills are original summaries based on reading notes. They contain no book text beyond short, cited quotations. Uses beyond each book's own subject (for example, composition applied to slides) are extensions, not the authors' words.
