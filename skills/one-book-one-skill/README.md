# One Book, One Skill (一书一 skill)

One book at a time, distilled into a working method for AI.

Each skill turns the core ideas of one book into steps an AI can follow when it thinks, works, or makes images, spaces, and writing. Each skill has a short video. Skill files (`SKILL.md`) are written in Chinese. Every README is in English.

Author: skill整理员

| # | Skill | Book | For |
| --- | --- | --- | --- |
| 01 | [Half Moon (半月)](half-moon/README.md) | Onishi Yoshinori's aesthetics trilogy (《日本美学三部曲》) | Japanese-style aesthetics for images, spaces, and writing |
| 02 | [Hollow (空处)](hollow/README.md) | Chen Guying, annotated *Laozi* (《老子注译及评介》) | Thinking, working, and making with Laozi's "useful emptiness" |
| 03 | [Where the Eye Lands (落点)](where-the-eye-lands/README.md) | Ian Roberts, *Mastering Composition* (《构图的艺术》) | Composition for images, slides, covers, photos, and spaces: one focal point |

## How to use

Copy a skill folder (for example `half-moon`) into your skills directory (for Claude Code: `~/.claude/skills/`).

## Notes

Skills are original summaries based on reading notes. They contain no book text beyond short, cited quotations.
