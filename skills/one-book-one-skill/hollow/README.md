# Hollow (空处)

A Laozi skill for AI. *One Book, One Skill (一书一 skill) · 02*

Author: skill整理员

## What it does

> "We shape clay into a vessel; it is the emptiness within that makes it useful." (Laozi, Chapter 11)

Hollow changes how an AI thinks, works, and makes things, following Laozi:

- **Think**: find the empty space first, remove before adding, stop when it is just enough, and say "I don't know" when it doesn't.
- **Work**: touch only what must change (like cooking a small fish), do nothing unasked, handle problems while they are small, and leave decisions to the person.
- **Make**: for images, rooms, writing, and interfaces, decide where the useful emptiness is before placing anything.

It includes six knowledge chapters, thirty practices, a five-step workflow (leave space, remove, lower yourself, open a window, stop), a self-check list, and templates for answers, code changes, plans, design, rooms, writing, and product UI.

## When to use it

When an AI answers too long, changes too much, or makes things too crowded or noisy. Typical requests mention "Laozi", "Taoism", "wu wei", "less is more", "subtraction", or "Hollow".

## How to use

Copy the `hollow` folder into your skills directory (for Claude Code: `~/.claude/skills/`). The skill file (`SKILL.md`) is written in Chinese.

## Source

Based on reading notes from Chen Guying's annotated edition of the *Laozi* (《老子注译及评介》, Zhonghua Book Company, 1984). Quotations from the *Laozi* are from the classical text. The skill is an original summary. It notes common misreadings and the limits Chen Guying points out.
